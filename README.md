# Gym Tracker

Aplicação web para organizar treinos e acompanhar evolução física.

## Sobre o projeto

O Gym Tracker reúne o acompanhamento de treinos e dados de evolução em uma interface web responsiva.

## Tecnologias

- React e JavaScript
- Vite
- Firebase
- React Router e Recharts

## Funcionalidades

- Organização de treinos
- Acompanhamento de evolução física
- Visualização de dados com gráficos

## Como executar

Requer Node.js.

```bash
npm install
npm run dev
```

Comandos de qualidade disponíveis: `npm run lint`, `npm test` e `npm run build`.
